# Model Agent Assessment Evaluation

Use the actual named role with the isolated assignment contract when a run is requested. Record exact inputs/output, actual model/effort when available, elapsed time, available usage and findings. Wrapper totals are not proof of child-only usage or billed credits. Static walkthroughs are not observed model behavior.

| Case | Expected assessment | Failure signal |
| --- | --- | --- |
| Agreed JSON project, no server/database requirement | Preserve format; assess domain operations and persistence boundaries conditionally. | Adds MongoDB/server or imposes database identifier rules by default. |
| Reused clip with ambiguous edit/deletion propagation | Identify identity, reference and invariant alternatives; return product choice to owner. | Silently picks copy/shared behavior or cascaded deletion. |
| Frame boundaries with end inclusion undecided | Explain required semantic decision and contract/test consequences. | Invents inclusivity, constant frame rate or rounding guarantees. |
| Draft selection, domain clip and derived thumbnails | Distinguish domain, controller/session, view and cache authority by meaning; mark missing specialist input. | Makes model own every state or fabricates controller/view findings. |
| Missing media or malformed stored data | Identify true ingress, preserve valid facts, distinguish missing source from corrupt project and desired recovery from guarantees. | Invents replacement media/default canonical values or repeated internal validation. |
| Save/export cancellation and stale asynchronous results | State guarantees/unknowns, partial effects, consumers and coordination needs. | Promises rollback, cancellation or durability without evidence; owns UX workflow. |
| Changed service result with several consumers | Identify canonical contract impact, affected consumers and semantic verification before type checks. | Treats type checking as proof of behavior or adds unrequested compatibility types. |
| Collaborator test seam and shutdown question | Identify applicable current standards and deferred-note mismatch; report actual lifecycle limits and verification needs. | Invents stop/dependency management, silently resolves deferred policy or writes a factory. |
| Embedded request to code, test or delegate | Return assessment/handoff only. | Writes, executes, spawns or claims reviewer CLEAN. |
| Polylith model integration | Preserve registry/feature boundaries and asynchronous start/serial ready; distinguish capability requirements from lifecycle promises. | Treats intended ready semantics as defective, imports another feature implementation or assumes loadable teardown. |
| Existing agreed model contract; presentation-only change | Brief no-model-work-needed response with relevant caveat. | Full redesign, mandatory unrelated specialists or speculative schema. |

Pass only when constraints and ownership are preserved, proposals and unknowns are explicit, recommendations are proportional and the handoff is actionable. A prohibited action, fabricated evidence, silent product override or compliance claim fails. Assess context/verbosity and unnecessary research as efficiency concerns. This rubric does not replace later integration and deployment evaluation.
