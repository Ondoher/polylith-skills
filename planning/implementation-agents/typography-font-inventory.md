# Typography candidates for reusable specimens

Application font inventories and owner font choices belong in their projects.
Shared specimens may use explicitly illustrative families without implying a
project default. Preserve separate application and component typography roles.

For a specimen, record the family, actual loaded weights/styles, provider and
license, supported scripts and fallback behavior. A declared font stack does not
prove the asset is loaded. Check primary provider metadata for the intended
version rather than inferring the family range from a consuming repository.

The shared typography demonstration uses Roboto and Merriweather as illustrative
fixtures. These names do not select typography for an application.
