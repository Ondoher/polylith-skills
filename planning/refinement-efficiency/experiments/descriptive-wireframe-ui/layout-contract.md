# Isolated layout author contract

Use the assigned frozen usage packet, source, research and scenario list. Author
the whole assigned composition surface and the specified contextual states. This
is design artifact work, not application implementation or canonical persistence.
The shared source decisions take precedence over research advice. Do not change
product policy. Record source gaps, decisions and clarification requests externally.

In **descriptive mode**, save `layout.md`. Give stable region/component IDs,
source action/state references, hierarchy/grouping, relative placement, context
switches, task priority, focus sequence and growth/wrap/scroll intent. Describe
each assigned scenario and its consequential visible outcome. Do not emit pixel
geometry, font/color choices, intermediate scenes or screenshots. UI will choose
concrete visual treatment from the same design language and research.

In **rendered mode**, save `wireframe.json` using the shared rendering contract.
Use neutral structured scenes and meaningful states/outcomes, then render and
inspect them. Save `layout-notes.md` with scope, intent and external questions.
Use reusable parts and scene changes rather than copying the workspace per state.

Both modes must represent the same source actions, scenario set and behavior.
Clarifications, TODOs, uncertainty and designer commentary belong outside the
canvas. Underspecified placed components may be placeholders; supplied functions
must be represented. Do not read other run directories, historical comps or prior
review findings. Save completed units as useful natural batches. No added self
review loop; rendered-mode author inspection remains required.

Record stage start, inputs-ready, first-unit-saved and authoring-end UTC markers.
Include the exact artifact hash, sizes, scenario coverage, any correction and its
cause in `author-receipt.json`. Do not label all elapsed time as reasoning.

You may write only your assigned run's `layout/` directory and use the shared
deterministic rendering/marker commands. Read the input packet and contract once,
using bounded independent read waves and continuations for large files. You are
not alone: do not touch unrelated files. Fix errors, preserve progress, decide
unknowns using supplied evidence, and report those decisions. No separate model
session, backend, proxy, redirect, observer or live product mutation.
