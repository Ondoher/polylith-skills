# Shared comparison limits

Both paths use the same existing renderer. Media imagery is schematic: there are
no video/raster assets in the scene vocabulary. Authoring preserves composition,
crop, time and selection meaning through its supported visual primitives and
numeric relationships. This is not a live video application test.

The production preview renderer fixes heading size at 22 pixels and uses its
system font treatment. The frozen accepted language calls for a 20-pixel heading
and Roboto. UI authors must use the exact shared theme tokens and document these
unsupported typography details instead of inventing different replacements.

Independent reviews still assess the resulting usability, hierarchy, coherent
styling, legibility and semantic coverage. Do not classify these identical,
documented renderer constraints as author-specific repair findings. Experimental
approval does not claim exact production typography, photographic media fidelity,
runtime interaction, keyboard behavior or real persistence verification.
