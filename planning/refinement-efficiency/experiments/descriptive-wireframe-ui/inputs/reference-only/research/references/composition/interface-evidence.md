# Actual interface evidence

Accessed and downloaded on 2 October 2026. Every local image below was inspected using `view_image` during this research. These are official documentation images, not generated comps. Visible relationships support the observations; a static image does not prove operation timing, failure recovery, pointer hit areas, or present-day application builds.
