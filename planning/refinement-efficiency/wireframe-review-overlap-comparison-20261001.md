# Wireframe review placement comparison

All three paths reached an independently accepted timeline wireframe from the **same frozen revision 4**, source packet, fixture, and artifact binding (`aebb31945ab696f0309be7db8aa96a2aebd6b29ddd8d1721e620284087d72c31`). Authors and reviewers used `gpt-6-astra` at `ultra` effort. The [event-derived metrics](wireframe-review-overlap-comparison-20261001-metrics.json) and private [branch setup](../../.codex-tmp/wireframe-comparison-20261001) preserve how the paths were compared. The first path is the already completed [progressive-feedback trial](wireframe-ui-progressive-review-20261001.md); the other two were isolated branches of its immutable first draft.

The external-only duration combines the **reused** 10m03s revision-4 review and the later branch's 16m20s from author start through pass, including the original 56-second frozen-draft-to-review-start gap. It excludes the idle time between those separate sessions. Reviewer active times must not be added to elapsed time where author and reviewer overlapped.

## What each review caught

The blinded self-review branch spent **14m06s** on its first audit and repairs. It expanded the initial 32 assertions to 37, found 16 needs-repair items in revision 4, then reduced that count to one in revision 5 and zero in revision 6. Its findings substantively overlapped **six of the seven** original external findings. It also noticed Undo appearing before a trim was committed, but did **not** cover what happens when Save, Add, selection, and other competing commands are used while the trim is pending. The independent reviewer rejected its otherwise clean revision 6 for that command boundary. A 38th source-linked check and a focused repair produced revision 7, which passed.

The external-only branch received the saved seven revision-4 findings and made one focused repair revision in **7m20s**, without creating or running an author checklist audit. The independent review confirmed all seven were resolved but rejected revision 5 because the selected object lost its visible selection cue during staged Add, commit, and failure. A focused correction and re-review passed revision 6. That selection problem had been identified and repaired by the self-review branch before its first submission. Thus each path caught a different issue the other missed on its first submitted result.

The progressive path sent all seven initial findings while the author was still self-reviewing. It was **38 seconds faster** than sequential self-review in these observed windows; that is within ordinary run variation. External-only was **3m24s slower** than sequential self-review in the reconstructed comparison. One nondeterministic run per path does not establish a stable speed ranking or credit advantage. The external-only path removed repeated author checklist work but required more reviewer activity; token and monetary usage were unavailable.

## Protocol limits and decisions

The branches copied only the exact revision-4 artifact, its preview and source context. The self-review author did not read prior findings; its reviewer did not read author audits or other branches. The external-only author received the exact earlier revision-4 diagnostic, so that review was reused rather than paid for twice. The earlier reviewer had seen a shared checklist after author audit notes were added; its strict blinding was already compromised, although the seven findings were bound to immutable revision 4. After submitting revision 5, the external-only author saw unrelated prior-trial summaries through an agent-status call. That exposure could not affect revision 5, but is a limitation for its later focused repair. The authors and reviewers also chose different bounded source/numeric helpers, adding variation to the measured time.

No live product, canonical workflow, or production agent code was changed. No separate model client, local model proxy, or direct backend call was used. These are static wireframe reviews; the upstream UX, UI comps, and runtime interaction behavior were not evaluated. A stronger credit comparison would capture per-agent usage and repeat the same three paths on another frozen draft, with immutable reviewer packets and no cross-branch status visibility.
