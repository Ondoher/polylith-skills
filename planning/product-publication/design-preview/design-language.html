Fieldbook / Shared visual reference

Design language

Calm surfaces, readable observations, and a clear next action. A reference for the visual decisions shared across the application.

Proposed separate documentSynthetic visual valuesFormat proposal 02

1 Visual direction

Fieldbook's sample interface uses warm pale surfaces and restrained green accents. The hierarchy gives the observation more attention than the surrounding controls. Borders distinguish editable fields, while feedback appears where it helps the gardener complete the task.

The production document would publish the existing validated design-language source. This page demonstrates presentation only; none of its visual choices override a product's accepted theme.

5 Shape and surfaces

The sample uses modest corner rounding, thin boundaries, and quiet background changes. Surface distinction does most of the work; elevation is reserved for cases that need separation from underlying content.
