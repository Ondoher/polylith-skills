1 Application overview

Start with the harvest history, then follow the gardener's path from a new observation to a saved entry.

Illustrative draftOne application areaOne identified form · one local use case

Fieldbook keeps the gardener's observations in a single Harvests area. The history is the starting point for reviewing earlier entries and recording a new harvest. The guide explains the screen in context before describing the recording flow.

1.1 The shared shell

The left navigation identifies the current area. The content region shows saved entries and exposes the main action, Record harvest. Starting a new entry changes the content region while keeping the application context visible.

1.2 Harvests

This area brings together the saved history and the task of creating an entry. Its recording flow needs more detail than this overview: it moves from entry details to review, then saving and the resulting history state, with correction and recovery paths.

1.2.1 Harvest entry form

IO-01 · Interaction object · Multi-step form

This form owns the date and note draft, its editing and review states, validation, and save recovery. It can open a supporting confirmation dialog; using that dialog remains part of the form's local use case. Opening it from history is the entry boundary; a successful save or cancellation closes it and returns to history. The use case below documents ways of using this identified form.

2 Coverage and open questions

The sample demonstrates one complete goal. The recording page follows six steps within IO-01, the Harvest entry form, including its confirmation dialog, return-to-edit, empty-note correction, cancellation, and save-failure recovery. History is shown as entry/exit context. Broader journeys can link local use cases across objects. It does not demonstrate a complete application's UX coverage.

Design coverage still to specify

Keyboard focus, assistive announcements, responsive product layouts, and history-browsing details are outside this synthetic example. Production documentation must show their actual source status.
