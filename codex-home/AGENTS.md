Review-agent lifecycle is owned by the global `review-standards` skill. When repository bootstrap is requested, the `bootstrap` skill must first load the Codex-root and repository-root instructions. If the repository-root `AGENTS.md` contains the standalone directive `Bootstrap profile: instructions-only`, bootstrap must skip `review-standards`, checkpoint-adviser startup, and generated standards-guide checks and proceed under the loaded instructions. Otherwise, the `bootstrap` skill must execute `review-standards` bootstrap mode. Dedicated standards reviewers run through that skill's eligibility gates. The optional checkpoint adviser is independent of those gates and judges only whether the current changes form a reasonable unit of functionality.

Resolve repository topics from the standalone `Topics folder:` directive in root `AGENTS.md`, defaulting to `.agents/topics`. Bootstrap records an existing `agents/topics` folder as an explicit exception when the directive and default folder are absent. During a bootstrapped reviewer session, treat a changed topics-folder location, its `active-topic.md` target, or an explicit change of governing topic as a lifecycle event. Before continuing implementation, execute `review-standards` topic-refresh mode so stale reviewer context is invalidated and applicable reviewers are refreshed. This is event-driven orchestration, not a filesystem watcher.
